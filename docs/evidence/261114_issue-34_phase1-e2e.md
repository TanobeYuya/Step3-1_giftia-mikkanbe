## 全件の照合（TC-01〜TC-07）

API の SQL を使わずに、DB の `products`・`product_scenes`・`product_facts` を SELECT で全件取り、Python で絞り込みと並べ替えをした。

- 絞り込み：在庫あり（stock > 0）に、各 TC の条件（シーンのタグを持つ、商品名・ブランド・説明文に「タオル」を含む、価格が 3,000〜6,000円）を足した
- 並べ替え：母の件数の多い順 → 販売数の多い順 → 商品ID（仕様 SP-05）
- 照合：絞り込んだ件数を API の total と比べた。並べ替えた上位100件を、API の上位100件と比べた

| TC | 条件に合う件数（DB） | API の total | 上位100件 | 母の件数が0の商品 |
| --- | --- | --- | --- | --- |
| TC-01 | 7,762 | 7,762 | 一致 | 7,460 |
| TC-02 | 4,503 | 4,503 | 一致 | 4,307 |
| TC-03 | 1,757 | 1,757 | 一致 | 1,631 |
| TC-05 | 493 | 493 | 一致 | 467 |
| TC-06 | 542 | 542 | 一致 | 498 |
| TC-07 | 4,011 | 4,011 | 一致 | 3,829 |

- 条件に合う商品の集合と API の total が一致するので、API が返す全件が条件を満たす（TC-02・03・05・06・07 の「全件」）
- 並べ替えの規則も、上位100件で API と一致した。母の件数が0の商品も集合に残り、0件にならない（TC-05）
