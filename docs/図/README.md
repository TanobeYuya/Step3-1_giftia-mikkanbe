| [02_企画書/](02_企画書/) | 企画書用の詳細な図（企画書_0〜5） | [改善企画書](../企画書/261122_Giftia改善企画書.md) |

## 図の決まり

- フォント：BIZ UDGothic
- 色：既存は灰色か層の色（画面＝青、API＝緑、DB＝紫）。変更・追加はオレンジ（#D83B01）と★。実装中は灰色の点線
- アイコン：draw.io の Azure（azure2）のアイコン

## 書き出し・開き方

draw.io のデスクトップ版で書き出すコマンド（Git Bash。`-p` はページ番号）:

```bash
"/c/Users/<ユーザー名>/AppData/Local/Programs/draw.io/draw.io.exe" -x -f png --width 2400 -b 20 -p 2 -o 01_設計書/ER図_2_変更後.png 01_設計書/ER図.drawio
```

- 拡大率（`-s`）で指定すると、Windows の表示倍率の影響で図が拡大され、右と下が切れることがある。幅（`--width`）で指定する
- VS Code：拡張「Draw.io Integration」で .drawio を開くと、編集できる
- BIZ UDGothic が入っていないパソコンでは、別のフォントで表示される（Windows 10 以降には標準で入っている）
