次のファイルの日本語を、`.claude/rules/japanese-writing.md` に従って自然な日本語に直してください。

対象: $ARGUMENTS

対象が空なら、何も変更せずに「対象のファイルのパスを指定してください」とだけ返してください。

## 手順

1. `.claude/rules/japanese-writing.md` を読む。
2. 対象のファイルを読み、文末の文体（です・ます／だ・である）と、英数字の前後のスペースの扱いを確認する。直すときはこれに合わせる。
3. 不自然な箇所を Edit で直す。意味・事実・数値・ID・コード・パス・URL・見出しの構成、ファイル先頭の frontmatter（`---` で囲まれた部分）は変えない。内容を足したり削ったりしない。
4. 判断に迷う箇所（専門用語の言い換えで意味が変わりうる箇所など）は直さず、返す一覧に書く。

## 返す内容

- 直した箇所の数と、代表的な直し方を3例まで（直す前 → 直した後）
- 直さずに残した、判断が必要な箇所（ファイル:行と理由）
- 「変更は `git diff <ファイル>` で確認できる」の1行
