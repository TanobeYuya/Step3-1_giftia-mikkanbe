# 日本語の書き方（文書・PR・Issue・コメント共通）

AI が書く日本語は翻訳調になりやすい。次を守って、人が書いたような自然な文にする。

## 文体

- 文末は文書ごとに統一する（「です・ます」か「だ・である」。既存の文書に合わせる）。箇条書きは体言止めか「〜する」でそろえる。
- 結論を先に書く。「以下に〜を示します」「〜について説明します」などの前置きは書かない。
- 1文は60字程度まで。1文に1つのことだけ書き、「〜し、〜し、〜」と読点でつながない。
- 「の」を3つ以上続けない。修飾語は、かかる語の近くに置く。

## 翻訳調・AI 調を直す

| 避ける | 直し方 |
| --- | --- |
| 〜することができる | 〜できる |
| 確認を行う、修正を実施する | 確認する、修正する |
| 〜することによって | 〜して、〜で |
| 〜となります、〜の形になります | 〜です |
| 〜させていただきます | 〜します |
| これは〜です、それにより〜 | 主語を省く。つなぎは「そのため」「すると」 |
| 〜される（受け身の多用） | 動作の主体が明らかなときだけ能動にする（「Claude によって設定が読み込まれる」→「Claude が設定を読み込む」）。主体が変わるなら受け身のままにする |
| 〜に関して、〜における | 〜について、〜の（必要なときだけ） |
| 重要なのは〜です、〜しましょう、〜ですね | 事実だけを書く |
| インプット、フィックス、アジェンダ | 入力、修正、議題（定着した技術用語はそのまま） |

## 変えないもの

コード、コマンド、パス、ID（例: F-03、#12）、URL、固有名詞、引用、表の列の構成。

## 体裁

- 太字は1段落に1か所まで。絵文字・感嘆符は使わない。
- 英数字と日本語の間の半角スペースは、既存の文書に合わせる。
